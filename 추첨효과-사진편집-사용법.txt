조 추첨 효과와 사진 편집 업데이트 (2026-10-24)

1. GitHub 업로드
압축을 풀고 public 폴더를 같은 위치에 덮어씁니다. 6개 화면 파일은 함께 올려야 합니다.
기존 파일을 전체 삭제하지 마세요. Render 배포 완료 후 Ctrl+Shift+R로 새로고침하세요.
test 폴더는 검증용입니다.

2. 조 추첨 효과
관객 노트북에서 /draw를 열고 '효과음 켜기'를 한 번 누르세요. 옆에서 음량을 조절할 수 있습니다.
호스트에서 번호를 지정하거나 '선택 선수 입장 장면 재생'을 누릅니다.
드럼 소리가 빨라지고 출발 신호등이 켜진 뒤, 잠깐 멈췄다가 조 번호가 공개됩니다.
공개 효과음 → 엔진 소리와 함께 해당 조 이동 → 도착 효과 순서입니다.
'전체 조 보기'는 진행 중 효과와 대기 중 효과를 모두 건너뜁니다.
번호에 따른 조 배정 규칙은 그대로입니다. 운영체제의 동작 줄이기가 켜져 있으면 효과를 간소화합니다.

3. 정보·사진 수정
참가자 카드에서 '정보·사진 수정'을 누르면 현재 화면에 편집창이 열립니다.
이름·자동차 이름·사진 등을 바꾸고 '정보·사진 저장'을 누르세요.
저장하거나 닫으면 검색 조건과 명단 위치가 유지됩니다.
사진을 고르기만 해서는 서버에 저장되지 않습니다. 저장 버튼을 눌러야 합니다.

4. 여러 사진 한 번에 넣기
먼저 호스트에서 어와나 또는 일반부를 선택합니다.
참가자 명단의 '사진 여러 장 한 번에 넣기'를 누릅니다.
'사진 여러 장 선택'에서 Ctrl 또는 Shift로 여러 파일을 고릅니다.
파일명 예시:
  김하늘.jpg        → 김하늘 선수 사진
  김하늘_자동차.jpg → 김하늘 자동차 사진
  1.jpg             → 1번 선수 사진 (번호 지정 후)
  1_자동차.jpg      → 1번 자동차 사진 (번호 지정 후)
자동차 사진만 모아서 넣을 때는 '기본 사진 종류'를 자동차로 먼저 바꾸세요.
파일명이 맞지 않아도 미리보기 옆에서 선수와 사진 종류를 직접 선택할 수 있습니다.
동명이인과 번호 추첨 대기 중인 번호는 자동 연결하지 않습니다.
'건너뛰기 / 직접 선택' 상태의 사진은 저장하지 않습니다.
같은 선수·같은 종류에 사진 두 장이 연결되면 하나를 건너뛰도록 변경하세요.
기존 사진이 있으면 '기존 사진을 교체합니다'가 표시됩니다.
대상을 확인한 뒤 '연결한 사진 N장 저장'을 누르세요.
JPG·PNG·WebP, 파일당 20MB 이하, 한 번에 최대 120장을 지원합니다.
사진은 자동으로 축소해 서버에 저장합니다. 일부 저장 실패 시 완료된 사진을 제외하고 다시 저장합니다.
