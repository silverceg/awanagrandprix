어와나 실시간 조 입장 화면 사용법

1. TV 노트북에서 기존 서버 주소 뒤에 /draw 를 붙여 여세요.
   호스트 화면 위쪽의 '조 추첨 화면 ↗' 링크로도 열 수 있습니다.
   TV 화면을 먼저 열어 둔 다음 등록해야 입장 장면이 바로 나옵니다.
   두 노트북은 같은 서버 주소를 사용해야 합니다.

2. 호스트 /host → 어와나에서 뽑은 스티커 번호와 이름을 등록하세요.
   1~4번은 1조, 5~8번은 2조, …, 37~40번은 10조입니다.
   등록 순서와 상관없이 번호에 맞는 고정 자리에 들어갑니다.
   번호를 비우면 자동 번호가 붙으므로 추첨 행사에서는 뽑은 번호를 입력하세요.
   선수 사진·자동차 이름·자동차 사진은 나중에 추가할 수 있습니다.

3. TV에서 선수 소개 → 조 번호와 같은 조 친구 공개 → 카드 이동 → 자리 도착
   순서로 보여 줍니다. 연속 등록하거나 명단을 한 번에 추가하면 순서대로 재생합니다.
   '전체 조 보기'는 대기 중인 애니메이션을 건너뛰고 등록된 명단을 바로 보여 줍니다.

4. 이미 등록한 선수는 호스트의 '번호로 만나는 우리 조'에서 선수를 선택하고
   '선택 선수 입장 장면 재생'을 누르세요. 중복 등록할 필요가 없습니다.
   새로고침하거나 다른 TV에서 열면 저장된 전체 명단이 바로 보입니다.

5. 어와나 1~40번을 모두 등록하면 '이 10개 조로 예선 시작'을 누르세요.
   공개 화면과 동일하게 번호 4명씩 실제 경기 조가 저장됩니다.
   번호 누락·범위 오류·중복 자리가 있으면 시작할 수 없습니다.
   01번과 1번은 같은 자리입니다. 오류는 명단의 '정보·사진 수정'에서 고치세요.
   이미 시작한 경기의 조 편성은 이 화면을 열어도 바뀌지 않습니다.

6. 경기를 시작할 때 TV를 /tv 또는 /leaderboard로 전환하세요.
   /draw는 어와나 조 공개 전용 화면입니다.
   일반부 18명(41~58번)은 일반부 탭의 기존 수동 조 편성을 사용합니다.

업데이트 방법
- 이번 ZIP에는 이전 open41 버전과 달라진 파일만 들어 있습니다.
- 압축을 풀고 lib, public, test 폴더는 폴더째 올려 기존 같은 경로를 덮어쓰세요.
- 폴더 안의 파일을 전부 꺼내 저장소 첫 화면에 한꺼번에 올리지 마세요.
- 기존 파일 전체 삭제는 하지 마세요. 이미지·폰트 등 나머지 파일도 필요합니다.
- Render는 GitHub 업로드 후 새 배포가 완료되어야 적용됩니다.
- 로컬 F:\awana로 실행한다면 서버를 재시작하고 두 화면을 새로고침하세요.
- 실제 명단·사진·경기 기록은 이번 변경 파일에 포함되지 않습니다.
