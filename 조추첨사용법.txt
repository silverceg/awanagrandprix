어와나 사전 등록 → 당일 번호 추첨 사용법

1. 행사 전: /host → 어와나 → 이름부터 등록해요
   이름과 자동차 이름을 등록합니다. 이름만 먼저 등록해도 됩니다.
   명단의 '정보·사진 수정'에서 선수 사진과 자동차 사진을 저장합니다.
   이때 번호는 붙지 않으며 조 추첨 관객 화면에도 공개되지 않습니다.
   엑셀에 번호가 있어도 어와나 사전 등록에서는 번호를 가져오지 않습니다.

2. 기존 번호가 있는 명단을 다시 추첨하려면
   '기존 명단으로 추첨 다시 준비' → '명단 유지 · 번호 추첨 준비'를 누릅니다.
   모든 어와나 번호를 추첨 대기로 돌립니다. 이름·자동차 이름·사진은 유지됩니다.
   이미 경기를 시작한 상태에서는 사용할 수 없습니다.

3. 추첨 당일: TV에서 같은 서버 주소의 /draw 를 먼저 엽니다.
   효과음을 원하면 TV에서 '효과음 켜기'를 한 번 누릅니다.
   호스트 위쪽 '추첨 당일 · 번호만 지정'에서 선수를 고르고,
   뽑은 번호 1~40을 입력한 뒤 '번호 지정하고 입장'을 누릅니다.
   저장해 둔 이름·자동차 이름·사진으로 입장 장면이 재생됩니다.
   1~4번은 1조, 5~8번은 2조, …, 37~40번은 10조입니다.
   중복 번호는 저장되지 않습니다. 재생은 '선택 선수 입장 장면 재생'을 사용합니다.
   '전체 조 보기'는 대기 중인 애니메이션을 건너뜁니다.

4. 40명 모두 번호를 받은 뒤 '이 10개 조로 예선 시작'을 누릅니다.
   TV를 /tv 또는 /leaderboard로 전환하여 경기를 진행합니다.
   일반부 18명은 기존 방식이며 자동 번호는 41번부터, 조 편성은 수동입니다.

집에서 등록하고 교회 다른 노트북에서 이어 쓰기
- 두 곳에서 같은 온라인 서버 주소의 /host 를 열면 같은 명단을 사용합니다.
- localhost 주소는 각 노트북 자신을 뜻하므로 서로 다른 노트북의 자료가 공유되지 않습니다.
- 현재 앱의 명단과 사진은 서버의 SQLite DB에 저장됩니다.
- 무료 Render의 임시 디스크는 서버 중지·재시작·재배포 시 자료가 사라질 수 있습니다.
  다음 날까지 보존하려면 영구 디스크 또는 외부 DB 연결이 필요합니다.
  이번 사전등록 변경에는 외부 DB 연결이 포함되어 있지 않습니다.
- 호스트만 수정·삭제하려면 서버 환경변수 HOST_PIN에 8자 이상의 비밀번호를 설정합니다.
  관객은 /draw, /tv, /leaderboard를 로그인 없이 볼 수 있습니다.
  HOST_PIN이 없으면 현재 앱은 누구나 /host에서 수정할 수 있습니다.

변경 파일 적용
- 변경된 파일만 제공합니다. lib/public/test 폴더 구조를 유지해 같은 경로에 덮어씁니다.
- 기존 파일 전체를 삭제하지 마세요. data 폴더와 실제 명단·사진은 업로드하지 않습니다.
- Render에서는 새 배포가 완료되어야 적용됩니다. 로컬 서버는 재시작합니다.
- 화면을 새로고침한 뒤 사용하세요.
