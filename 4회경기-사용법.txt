어와나 그랑프리 - 본선 4라운드 운영 (2026-10-24)

새 규칙
- 예선·16강·준결승·결승 없이 전원이 본선 네 라운드를 진행합니다.
- 어와나 40명은 1~10조, 일반부 18명은 11~15조로 이어집니다.
- 매 라운드 모든 조가 한 번씩 경기한 뒤 다음 라운드를 시작합니다.
- 매번 1→2→3→4→1로 이동하여 각 선수가 네 레인을 모두 한 번씩 탑니다.
- 네 기록 중 가장 빠른 유효 기록으로 부문별 순위를 정합니다. 동점은 공동 순위입니다.
- DNF는 최고 기록 계산에서 제외합니다. 4회 모두 DNF면 순위가 없습니다.

경기 준비
1. 이름·자동차 이름·선수 사진·자동차 사진을 등록하고 저장합니다.
2. 어와나 조 추첨은 그대로입니다. /draw에서 효과음을 켜고 번호를 공개합니다.
   1~4번은 1조, 5~8번은 2조, ..., 37~40번은 10조입니다.
3. 40명에게 번호를 배정한 뒤 '이 10개 조로 경기 시작'을 누릅니다.
4. 일반부 18명(41~58번)의 수동 조를 편성하고 저장합니다.
   어와나가 10개 조일 때 일반부는 11~15조로 표시됩니다.
5. 두 부문 조가 준비되면 본선 1라운드 1조부터 자동 시작합니다.
   경기 시작 후에는 조 편성을 바꿀 수 없습니다.

자동 진행 순서
1라운드: 어와나 1~10조 → 일반부 11~15조
2라운드: 어와나 1~10조 → 일반부 11~15조
3라운드: 어와나 1~10조 → 일반부 11~15조
4라운드: 어와나 1~10조 → 일반부 11~15조 → 최종 결과
총 15개 조 × 4라운드 = 60경기입니다. 중간에 기록이 초기화되지 않습니다.
빈 레인도 함께 이동합니다. 수동으로 조를 추가하면 총 조 수와 일반부 시작 조 번호가 그에 맞게 늘어납니다.

호스트 기록 입력
- 화면의 실제 레인·이름·스티커 번호를 확인하고 초를 입력합니다.
- '기록 저장 후 다음 경기'를 누르면 저장과 이동이 함께 이루어지고 TV도 바뀝니다.
- 결과를 잠시 보여주려면 '기록만 저장 · TV 유지'를 누르세요.
  이후 '저장한 기록 확인 · 다음 경기'로 이동합니다. 다시 저장할 필요는 없습니다.
- 미입력 상태로 건너뛸 수 없습니다. 미완주는 DNF로 입력합니다.
- 다른 조를 조회했다면 '현재 경기 입력으로 이동'을 누릅니다.
- 진행 중 부문의 이전 기록은 조·라운드를 선택하고 수정 사유를 써서 저장합니다.
  종료된 부문은 읽기 전용입니다.
- 4라운드 15조를 마치면 두 부문 최종 순위가 확정됩니다. 진출자 선발은 없습니다.

TV와 전체 순위
- /tv: 현재 조와 본선 라운드, 실제 레인별 선수·사진·자동차 이름을 표시합니다.
  각 선수 카드에 1~4레인 기록을 누적하며, 개인 최고 기록은 금색 ★ BEST입니다.
  현재 주행 레인은 파란색, 미입력은 —, 미완주는 DNF입니다.
- /leaderboard: 처음부터 끝까지 두 부문을 함께 표시합니다.
  왼쪽 2/3는 어와나 40명과 상위 3명 카드, 오른쪽 1/3는 일반부 18명과 1위 카드입니다.
- 기록이 없는 선수는 이름·사진을 순위표에 올리지 않고 빈칸으로 기다립니다.
- /leaderboard?division=awana 또는 open은 부문 고정 화면입니다.
- 순위는 네 라운드를 통틀어 가장 빠른 기록으로 계산합니다.

기존 자료와 리허설
- 파일 업데이트로 실제 명단·사진·경기 기록을 지우지 않습니다.
- 이전 4회 방식으로 시작한 경기는 '기록 유지 · 본선 4라운드 적용'을 누르세요.
  명단·사진·조·기록을 유지하고 새 순서의 첫 미입력 경기로 이동합니다.
  이미 기록이 완료된 뒤쪽 경기는 자동으로 건너뛰어 재입력하지 않습니다.
  변경 전 상태도 사진과 함께 자동 백업합니다.
- 예전 2회 토너먼트 자료는 '4회 경기로 전환' 버튼을 사용합니다.
  이 버튼은 기존 기록을 자동 백업한 뒤 주행 기록을 초기화합니다.
  명단·사진·최초 조 편성은 유지됩니다. 이후 두 부문 준비를 마치고 시작합니다.
- 리허설 후 처음부터 다시 하려면 '경기 기록 초기화'에 '기록 초기화'를 입력합니다.
  기록·조 편성·진행 순서를 초기화하지만 명단·번호·사진은 유지합니다.
- 사진까지 복원하려면 전체 JSON 백업을 사용하세요. CSV는 기록표입니다.

파일 적용
- 변경 파일만 폴더 구조 그대로 덮어씁니다. 기존 파일 전체를 삭제하지 마세요.
- 로컬: 기록 저장 → 실행 창 Ctrl+C → 어와나-시작.cmd 재실행 → 화면 새로고침.
- Render: GitHub 같은 경로에 업로드 → 새 배포 완료 → 화면 새로고침.
- 서버 파일과 public 화면 파일을 함께 갱신해야 새 진행 순서가 적용됩니다.
- data 폴더와 실제 명단·사진·백업은 업로드하지 않습니다.
